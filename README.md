# Smart Rubber Yield Tracker

ระบบบันทึกและวิเคราะห์ผลผลิตยางพาราสำหรับชาวสวนที่กรีดเองและรับจ้างกรีดให้สวนอื่น

## ฟีเจอร์

- **บันทึกน้ำยาง:** ชั่งน้ำหนัก กรอกเปอร์เซ็นต์เนื้อยางแห้ง ระบบคำนวณน้ำหนักแห้งให้
- **ขายยาง:** บันทึกการขายผ่านพ่อค้าคนกลางหรือลานประมูล พร้อมเลขล็อตและเกรด ติดตามการรับเงิน
- **รับจ้างกรีด:** บันทึกงานให้สวนอื่น คิดค่าจ้างได้ 3 แบบ คือส่วนแบ่งเป็น % ของยอดขาย ฿ ต่อกก. แห้ง หรือเหมาต่อวัน
- **รายจ่าย:** บันทึกค่าปุ๋ย สารเคมี ค่าแรง น้ำมัน อุปกรณ์ และอื่นๆ
- **ราคายาง:** เจ้าของบันทึกราคาที่ได้ในแต่ละงวด ระบบบอกว่าราคาขึ้นหรือลงเทียบกับงวดก่อน
- **ปฏิทินและนัดหมาย:** ดูกิจกรรมรายวัน จดนัดหมาย เช่น วันขาย วันใส่ปุ๋ย และดูรายการที่ใกล้ถึงกำหนดบนหน้าหลัก
- **สรุปผล:** กำไรสุทธิ ตารางรายเดือน และเปรียบเทียบราคาขายผ่านพ่อค้ากับลานประมูล

## โครงสร้างโปรเจกต์

```
.
├── client/   Next.js 16 (App Router) + TypeScript + Tailwind CSS v4
└── server/
    └── node-ts-backend-scaffold/   Express 5 + TypeScript (โครงสร้างเริ่มต้น)
```

## เริ่มต้นใช้งาน

### Client

```bash
cd client
npm install
npm run dev          # http://localhost:3000
```

ค่าเริ่มต้นของ Next.js ใช้พอร์ต 3000 ถ้า backend ก็ใช้พอร์ต 3000 ให้เปลี่ยนพอร์ตใดพอร์ตหนึ่ง เช่น `npm run dev -- -p 3001`

การเรียก `/api/*` จาก client จะถูกส่งต่อไปยัง backend ตามค่า `BACKEND_URL` (ค่าเริ่มต้น `http://localhost:3000`) แก้ได้ใน `client/next.config.ts`

### Server

```bash
cd server/node-ts-backend-scaffold
npm install
cp .env.example .env
npm run dev          # ค่าเริ่มต้น PORT=3000
```

คำสั่งอื่น: `npm run build`, `npm start`, `npm test`, `npm run typecheck`

## ข้อมูลและการเก็บข้อมูล

- ตอนนี้ข้อมูลทั้งหมดเก็บในเบราว์เซอร์ของเครื่องนั้น (localStorage) ถ้าเปลี่ยนเบราว์เซอร์หรือเครื่อง ข้อมูลจะไม่ตามไป
- ครั้งแรกที่เปิดแอป ระบบจะใส่ข้อมูลตัวอย่างให้ดู ล้างได้ในหน้า **ตั้งค่า**
- ยังไม่มีการเชื่อมฐานข้อมูลฝั่ง server
